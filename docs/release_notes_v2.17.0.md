## 插件市场体验

- **安全状态筛选**：全部 / Ed25519 / HMAC / SHA256 / 未签名 / 已吊销；
- **来源徽章**：官方 / 本地 / 第三方；卡片显示安全状态标签；
- **依赖状态**：详情页展示「全部满足」或「缺失 …」；
- **安装失败回滚**：解压失败自动清理半成品目录；
- **安装后提示**：提示重载插件（插件面板 → 重载）或重启。

## 大文件性能

- >10MB 自动启用**大文件模式**（关闭折叠/彩虹缩进/缩进参考线）；
- 同步加载阈值 32MB → **64MB**；>64MB 仍走异步批量加载；
- **50MB / 3,000,001 行打开实测 1.46s**（目标 <3s 达成）；
- 实时沙箱诊断大文件阈值可配置：
  `QINGCAO_LIVE_DIAGNOSTICS_MAX_MB` / QSettings（默认 5MB，1~512MB）；
- 性能基准新增 `open_50mb`（阈值 3.0s）。

## 无障碍深化

- 可访问名称自动补全（文本 → 提示 → objectName → 类型名）；
- 界面字体缩放 0.8~2.0（设置 → 常规 → 无障碍），两阶段应用避免继承漂移；
- 键盘焦点环（四主题下均可见，`palette(highlight)`）；
- 键盘无障碍审计工具 `tools/audit_keyboard_a11y.py`（入 CI）：
  171 项菜单 / 54 项快捷键（31.6%）、缺少名称可聚焦控件 0；
- 验证清单 `docs/manual_validation_v2.17_a11y.md`。
