# 青草编辑器 v2.2.0 发布说明

> 发布日期：2026-10-20 · 平台：Windows x64 · 便携版（免安装）
> 版本权威来源：`version.py`（`2.2.0`）

---

## 一句话概括

这一版把此前"代码完整但用户用不到"的能力全部接了出来（项目/任务、会话快照、
代码模板、多键快捷键、本地片段库），并修掉了一批**真实使用中会丢数据或
让功能看起来坏掉**的缺陷（保存静默失败、UTF-16 文件打不开、编辑后丢 BOM、
行尾风格被改写、面板永远深色、状态栏文字不可见、多屏窗口跑丢、200% 缩放
下编辑器只剩 3 行）。

---

## 新增功能

### 项目（新的一级菜单）

`文件` 旁边新增 **项目** 菜单，把"项目根"作为一个正式概念：

* **📁 打开项目…** —— 选一个目录作为项目根；
* **🕘 最近项目** —— 记住打开过的项目，一键切回（持久化在
  `data/workspace.json`）；
* **⚙ 项目设置…** —— 用项目自己的 `.qingcao/settings.json` 覆盖编辑设置
  （Tab 宽度 / 缩进方式 / 换行符 / 默认编码）；
* **🧰 任务面板** —— 读取项目里的 `.qingcao/tasks.json`（也兼容旧的
  `.qingcao-tasks.json`），双击任务运行并查看输出。

### 会话快照

`文件 → 📸 会话快照…`：把"当前打开的所有文件 + 光标位置 + 窗口布局"
存成快照，随时一键恢复。恢复前会统一提示保存未保存的修改，
避免"恢复一半、前面的标签被关掉了"。

### 从模板新建

`文件 → 🧩 从模板新建…`：内置 8 个模板（Python 类/函数/测试/主程序、
JS 函数/类、`.gitignore`、`README`），按模板**动态生成占位符输入框**，
支持实时预览。

### 多键快捷键（VSCode 风格）

`Ctrl+K` 前缀 + 第二键：

| 序列 | 功能 |
|---|---|
| `Ctrl+K Ctrl+S` | 全部保存 |
| `Ctrl+K Ctrl+W` | 关闭所有标签 |
| `Ctrl+K Ctrl+C` | 注释切换 |
| `Ctrl+K Ctrl+F` | 格式化文档 |
| `Ctrl+K Ctrl+T` | 会话快照 |
| `Ctrl+K Ctrl+D` | 对比文件 |

设计上只拦截"带 Ctrl/Alt + 焦点在编辑器 + 无模态窗口"的按键，
普通输入不会被吞。

### 代码片段库（本地）

`工具 → 📚 代码片段库…`：从**本地片段包目录**导入代码片段
（默认 `data/snippet_packs`，可自选目录），按语言/关键词筛选，一键导入
本地片段库。

> 说明：原"网络片段市场"指向的 API 实测返回 HTTP 404（仓库不存在），
> 已改为本地片段包库 —— 零运维、零信任风险。

### 其他新入口

* `工具 → ⏱ 性能剖析…` —— cProfile 性能报告（Python 帧）；
* `帮助 → 📉 崩溃统计` —— 崩溃记录汇总；
* `视图 → 面板 → LSP 状态 / 撤销历史 / 任务`；
* `文件 → 导出 PDF / HTML`；
* `编辑 → 📊 列编辑器…`（`Alt+Shift+I`）、`工具 → 🔀 对比文件…`；
* 书签子菜单（`Ctrl+F2` / `F2` / `Shift+F2`）。

## 修复的关键缺陷

### 数据安全类

| 缺陷 | 后果 | 修复 |
|---|---|---|
| 保存时 `os.replace` 遇瞬态占用直接失败 | Ctrl+S **静默失败**（实测 6 次里 1~4 次） | 10 次短退避重试 |
| UTF-16/32 文件被判为"二进制" | 弹框询问，选"否"后**打不开** | 多级文本判定（BOM / UTF-8 / UTF-16 交替 NUL） |
| 编辑 UTF-16 文件后保存**丢 BOM** | 记事本/Excel/部分编译器误判编码 | 保存时补回 BOM |
| 保存把混合换行统一成 LF | 只改一个字，**整个文件行尾风格被改写**，git diff 全文件变动 | 保留每行原行尾符号 |
| 草稿恢复永远为空 | 崩溃后**恢复不到内容** | 修复 `Document.list_drafts()` 调用名 |
| 快照目录/片段库路径为相对路径 | 换目录启动后快照、导入的片段"消失" | 改为从应用根目录派生绝对路径 |

### 界面可用性类

| 缺陷 | 后果 |
|---|---|
| 启动时主题没应用到停靠面板 | 编辑器浅色、面板**全黑**，目录树像坏了一块 |
| 状态栏文字 `QStatusBar QLabel` 白底白字 | 行/列、编码、行尾符**完全看不见** |
| 搜索结果树写死深色且无 `refresh_theme` | "文件 / 匹配内容"永远黑块 |
| 多屏窗口几何恢复不感知多屏 | 窗口每次启动被拉回主屏；大屏换小屏后**大半在屏幕外** |
| 200% 缩放仍默认开 4 个面板 | 编辑器只剩 **3 行**，搜索选项被裁 |

### 性能类

| 项目 | 修复前 | 修复后 |
|---|---|---|
| 列编辑 100k 行 | 外推约 22 分钟（O(n²)） | **3.68 秒**（批量重建） |
| 10MB 文件打开 | 34.9 秒（逐块 append） | **0.00 秒**（≤32MB 单次 setText） |
| 2MB 文件切行尾+保存 | — | **0.11 秒** |

## 移除

* **实时协作（P2P）**：原实现是裸 TCP 监听 `0.0.0.0:52000`，
  **无加密、无认证、无 NAT 穿透**。接上 UI 等于把"局域网内无密码共享
  编辑端口"暴露给用户。要做对需要加密 + 认证 + 可达性 + 双端联调环境，
  属独立立项，故本版**删除**。
  （未来若做，建议先定安全模型再写代码。）

## 升级注意事项

1. **配置兼容**：`QSettings`（HKCU\Software\QingCao\Editor）结构未变，
   主题、快捷键方案、偏好设置全部沿用；
2. **新增数据目录**（都在应用根 `data/` 下，便携版随包内）：
   `workspace.json`（最近项目）、`snippet_packs/`（片段包）、
   `snapshots/`（会话快照）、`snippets.json`（导入的片段）；
3. **片段市场**：改名为"代码片段库"，不再联网；
4. **首次启动**：若系统缩放 ≥150%（或小屏），默认只打开目录树面板，
   其余从 `视图 → 面板` 按需打开（这是为了提高 200% 下的可用性）。

## 已知限制（如实说明）

* **单机验证范围**：本版本在 Windows 10 x64（1920×1080 @125%）上验证；
  `QT_SCALE_FACTOR` 模拟了 100%/125%/150%/200% 缩放，
  但**真实双显示器**与**运行时跨屏拖动触发 DPI 变化**未物理验证；
* **Windows 系统级缩放真实生效**需注销，未实测（已用 Qt 缩放等效验证）；
* **长时间运行内存**：只有单次会话数据，未做 24h+ 泄漏测试；
* **输入法（IME）** 组合输入未专项测试；
* **安装包**：本版提供便携 ZIP；Inno Setup 安装包未编译（本机无 ISCC）。
