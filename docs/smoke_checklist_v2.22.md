# v2.22 P2 体验冒烟清单（人工部分）

> 目标：验证 v2.21.2+ 三个新功能是否可用，并收集真实反馈。
> 反馈方式：帮助 → 💬 反馈与建议 → 类型选「体验反馈」（仅本机保存）。
> 启动：`python main.py`（源码，含 v2.22 稳定性修复）或运行 `dist\QingCaoEditor\QingCaoEditor.exe`（v2.21.2）。

## 1. 终端（约 2 分钟）
1. 打开「视图 → 面板 → 终端」，或按 `Ctrl+Shift+` 反引号（注意不是 Python 控制台的 `Ctrl+` `` ` ``）；
2. 输入 `echo hello` 回车 → 看到 `hello` 与 `[退出码 0]`；
3. 点 `+` 新建第二个标签 → 在新标签输入 `cd C:\Windows` → 显示 `cwd`；
4. 输入 `powershell -Command "Write-Host \"`e[32mgreen`e[0m\""` → 输出绿色（ANSI 生效）；
5. 关闭第二个标签 → 第一个标签仍可用；关闭面板无残留进程。

**预期**：多标签独立 cwd、颜色正常、关闭清理正常。
**记录**：若异常，反馈内容写「终端 + 步骤 + 现象」。

## 2. 多语言（约 1 分钟）
1. 设置 → 界面语言 → 繁體中文 → 重启；
2. 检查菜单（檔案/編輯/設定）、插件市场标题、关于对话框；
3. 设置 → 界面语言 → 日本語（试点）→ 重启 → 检查 ファイル/設定/プラグイン市場；
4. 设置 → 界面语言 → 한국어（试点）→ 重启 → 检查 파일/설정；
5. 切回 简体中文。

**预期**：繁体完整；日/韩为试点，未翻译项显示中文属正常。
**记录**：翻译错误/乱码/缺字请附截图或菜单名。

## 3. 插件市场（约 2 分钟）
1. 工具 → 🧩 插件市场 → 注册表 URL 填公网地址：
   `https://github.com/TomJerryGit/qingcao/releases/download/plugin-registry/registry.json`
2. 应用并刷新 → 应显示 13 个插件；
3. 安装 `wordcount_sandbox` → 校验下载 → 安装成功 → 重载；
4. 再次「检查更新」→ 若本地 1.0.0，应提示 1.0.1 → 更新 → 验签成功；
5. 详情页给该插件打 4 星 + 简评 → 保存 → 卡片显示「★ 4 本地」；排序选「按本地评分」。

**预期**：下载/校验/安装/更新/评分均正常。
**记录**：失败步骤 + 提示信息（注意不要粘贴 token/私钥）。

## 4. 提交反馈
- 帮助 → 💬 反馈与建议 → 类型「体验反馈」→ 描述结果 → 保存到本机；
- 之后运行 `python tools/feedback_report.py` 可汇总到 `docs/user_feedback_report.md`。

> 自动冒烟：`python tools/smoke_check.py` → `docs/smoke_report_v2.22.md`。
