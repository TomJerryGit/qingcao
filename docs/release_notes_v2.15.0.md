## 一句话概括

v2.15.0 完成沙箱诊断按文件聚合、python_debugger 受限求值安全加固，
并落地问题面板来源过滤/清除、实例上限设置 UI 与插件市场离线目录 MVP。

---

## 新增功能

### 沙箱诊断按文件聚合
- 对所有已打开文件分别运行沙箱子进程诊断；
- 问题面板按文件分组展示（来源 `sandbox:<插件名>`）；
- 实时诊断仅计算当前文件，避免多文件频繁 RPC。

### 问题面板来源过滤 / 清除
- 过滤：全部来源 / 仅沙箱 / 仅非沙箱；
- 🧹 一键清除沙箱诊断，保留 LSP / 普通插件诊断；
- 宿主接口 `MainWindow.clear_sandbox_problems()`。

### 实例上限设置 UI
- 设置 → 常规 → 多实例：新窗口实例上限 1~10（默认 3）；
- 持久化到 QSettings；`QINGCAO_MAX_INSTANCES` 环境变量优先。

### 插件市场离线 MVP
- `build_market_catalog()` 从本地插件 manifest 构建市场目录
  （分类/许可/主页/关键词/权限/沙箱状态）；
- 远程注册表不可用时自动使用本地目录兜底，市场不再空白。

## 安全加固

- python_debugger 新增受限表达式求值 `_safe_eval`：
  仅表达式、拒绝 dunder/危险内建（open/exec/eval/compile/__import__ 等）、
  长度限制 4000 字符；
- 复核文档：`docs/security_review_python_debugger_v2.15.md`。

## 验证

- 分片并行全量：109 个测试文件 → 2 片全部通过；
- ruff 0；`tools/check_version` 通过；
- 新增测试：聚合诊断、调试器安全、问题面板过滤/清除、实例上限、市场目录。

1. v2.14.2 → v2.15.0 无数据迁移；
2. 调试器表达式受安全限制；如遇受限表达式可反馈白名单需求；
3. 插件市场离线目录为只读展示，在线安装尚未启用。
