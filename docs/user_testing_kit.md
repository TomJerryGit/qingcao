# 用户任务测试方案（Sprint 2 / task-36）

## 目标

验证新用户能否在 **5 分钟内**完成一次真实任务；收集阻断点，而不是收集功能愿望。

## 招募

- 5–10 人，至少 3 人非开发者；
- 来源：朋友/社区/开发者群；可提供小额激励；
- 需明确同意：录屏/笔记仅用于产品改进，可选匿名。

## 任务脚本（约 15 分钟）

1. 安装并首次启动（记录是否卡住）；
2. 打开/新建 Python 或文本文件，编辑并保存；
3. 使用全局搜索找到一个词；
4. 打开 AI 助手，解释选中代码（可用测试 Key）；
5. 安装一个插件并启用；
6. 退出并重新打开，确认文件恢复。

## 记录字段

| 字段 | 说明 |
|---|---|
| 用户编号 | U01… |
| 背景 | 开发者/非开发者 |
| 完成/未完成 | 每个任务 |
| 用时 | 秒 |
| 阻断点 | 原话/界面位置 |
| 严重度 | P0 阻断 / P1 困难 / P2 建议 |

## 记录模板（真实执行后填写，禁止代填）

| 用户 | 任务1 | 任务2 | 任务3 | 任务4 | 任务5 | 任务6 | 阻断点 |
|---|---|---|---|---|---|---|---|
| U01 | - | - | - | - | - | - | - |

## 内部 Dogfood（先做）

- 用全新 Windows 用户目录/虚拟机，按脚本走一遍；
- 记录 ≥3 个首屏阻断点；
- 不替代真实用户数据。

## 产出

- `docs/user_test_round1.md`（真实数据，空表待填）；
- 阻断点清单 → 用于 task-39 削减/优化。
