## 新增：插件子进程沙箱（实验特性，默认关闭）

### 工作原理

1. manifest 显式 `"sandbox": true` 的插件，加载器在**扫描阶段排除**，
   主进程不 import 其代码；
2. 宿主惰性启动子进程 worker，通过 **JSON Lines RPC** 代理只读扩展点：
   `symbols` / `hover` / `completion` / `describe`；
3. 调用带超时；插件异常/崩溃不影响主程序，自动降级为空结果并标记
   `degraded`，支持 `restart()`；
4. 启动时使用 `{"ready": true}` 握手，导入失败即报错（消除竞态）；
5. 退出时统一关闭所有沙箱子进程（无孤儿进程）。

### 安全边界（如实说明）

- 当前 RPC **只支持只读扩展点**；依赖菜单/诊断/状态栏的插件
  （如 spell_check）暂不能迁移，后续需扩展受限协议；
- 方法白名单在客户端与 worker 双重限制；
- 默认关闭：现有插件完全不受影响。

### 如何试用

查看 `plugins/sandbox_demo/` 示例插件（默认 `enabled: false`）：
把 manifest 的 `enabled` 改为 `true` 后重启，打开 `.sdemo` 文件，
`## 标题` 会由子进程计算并出现在大纲中。

## 性能

### 主题切换：1s+ → 130-210ms

- 根因实测：应用级 `QApplication.setStyleSheet` 触发全控件样式重算
  （90-424ms），与延后插件激活撞车时可达 2.3s；
- 改为**窗口级 QSS**（实测 35-49ms）+ `apply_palette()` 兜底；
- 主题切换期间**暂停延后插件激活**，避免两件重活撞车；
- 实测真实切换：130 / 159 / 213ms。

### 输入延迟（v2.5.2 已交付，本版包含）

- provider 同步内存缓存 + 单块快写 + 撤销栈惰性物化；
- 211 → **57µs/键**（`typing_2000` 阈值 0.20s）。

## 升级注意事项

1. v2.5.2 → v2.6.0 无数据迁移；
2. 沙箱默认关闭，无需配置；

4. 主题切换改为窗口级 QSS，独立非子对话框的主题覆盖待人工验证。

## 已知限制

- 沙箱目前仅支持只读扩展点；不支持诊断/菜单/状态栏类插件；
- 主题切换未覆盖所有独立顶层对话框（需人工验证后补齐）；
- 真实双显示器 / 跨屏 DPI 变化未物理验证；
- 24h+ 内存泄漏与 IME 组合输入未专项测试；
- Inno Setup 安装包未编译（本机无 ISCC）。
