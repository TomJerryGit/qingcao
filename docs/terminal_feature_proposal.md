# 终端功能立项建议（v2.20.x P2）

> 状态：**立项建议**（未实现）
> 审计来源：v2.19 功能入口审计发现「终端」无实现、无菜单入口。

## 目标

在编辑器内提供集成终端（类似 VSCode 面板），支持运行命令、查看输出、与当前项目目录联动。

## MVP 范围

- 面板：底部停靠 `TerminalPanel`（QSplitter + QProcess）；
- 命令：启动 shell（Windows PowerShell / cmd；Linux bash）；
- 工作目录：当前项目根或当前文件目录；
- 输出：只读文本 + 清屏 + 复制；
- 菜单：`视图 → 面板 → 终端`、快捷键（待定）；
- 安全：默认不自动执行任何命令；不记录命令历史到磁盘（可选开关）。

## 非目标（MVP）

- 完整 PTY/ANSI 渲染（首版按行文本输出）；
- 多标签终端、分屏、SSH；
- 与 AI/任务系统深度集成。

## 设计要点

| 项 | 方案 |
|---|---|
| 进程 | `QProcess`，独立进程组；退出/崩溃时提示 |
| 编码 | Windows 统一 UTF-8（`chcp 65001` 或 PowerShell `-OutputFormat Text`） |
| 主题 | 复用 `theme_loader` 调色板 |
| 关闭策略 | 关闭标签/窗口时 terminate→kill，避免僵尸进程 |
| 测试 | 启动回显命令、清屏、主题适配、关闭清理（使用无害命令） |

## 风险

- 命令注入/误执行：MVP 由用户显式输入，不自动拼接；
- 平台差异（Windows/Linux）；首版优先 Windows；
- 进程泄漏：必须有 `closeEvent` 清理与超时 kill。
