# UI 与功能设计对齐 Notepad++（方案）

> 用户要求"UI 设计、功能设计参考 Notepad++"。本文给出逐项对照与改造
> 排期；**本轮已落地**项标注 ✅。

## 一、UI 骨架对照

| 区域 | Notepad++ | 青草现状 | 对齐动作 |
|---|---|---|---|
| 主窗口 | 经典单窗口：菜单/工具栏/标签/编辑区/状态栏 | 相同骨架 + 欢迎页 | 欢迎页可关闭（P1） |
| 菜单 | 文件/编辑/搜索/视图/编码/语言/设置/工具/宏/运行/插件/窗口/帮助 | 文件/项目/编辑/特色功能/视图/工具/帮助 | **重组为 NPP 式**：新增「搜索」「宏」「运行」「窗口」菜单，编码/语言收进「编码」子菜单（P0） |
| 工具栏 | 小图标（经典 16px）+ 提示 | 文本按钮 + 图标模式 | ✅ 视图 → 工具栏图标模式（emoji 生成 QIcon，无资源文件） |
| 标签栏 | 有，右键菜单丰富（关闭其他/复制路径/定位） | 有 | 补齐标签右键菜单项（P1） |
| **状态栏** | 分段可点击：`Ln: 1 Col: 1 Sel: 0`、`Length: 0`、`INS`、`Windows (CRLF)`、`UTF-8` | 已有行/列/编码/EOL/模式/内存 | ✅ 行列可点击跳转 + 悬停提示；后续：长度段点击=统计摘要、EOL 段点击=切换菜单（P0/P1） |
| 面板 | 浮动/停靠（Function List、Document Map、Folder as Workspace） | 停靠面板（目录树/大纲/小地图/问题/搜索等） | 保持；大纲已支持插件符号 ✅ |
| 欢迎页 | 无（空白新文档） | 有快速开始页 + 开关 | ✅ 视图 → 显示欢迎页（默认开；关闭后启动直达编辑区） |
| 主题 | 极简（默认亮色） | 4 套主题 + 跟随系统 | 不弱化，保持优势 |

## 三、排期

**P0（1 周，结构对齐）**
1. 菜单重组：新增「搜索」「宏」「运行」「窗口」顶级菜单 — **✅ 已落地**
   （非破坏式：新项不绑快捷键、旧菜单保留、命令面板兜底）；
   编码/语言收拢 — **✅ 已落地**：新增「编码」菜单（含换行符子菜单）
   与「语言」菜单（自动识别 + 声明式语言包列表）。
2. ✅ 状态栏可点击（行/列→跳转）；补 EOL/编码段点击菜单。
3. 状态栏"长度"段（字符数）点击 → 弹出统计摘要（NPP Length 段）。

**P1（1~2 周，体验贴近）**
4. 工具栏纯图标模式 + 图标体系（SVG，见优化计划）。
5. 标签右键菜单补齐（关闭其他/关闭右侧/复制路径/在目录中显示）。
6. 欢迎页可关闭（首选项开关）。
7. 商店兼容性徽章 + 全部更新 UI（基础设施已就绪）。

**P2（后续）**
8. 打印/打印预览；多实例与拖放；拼写检查（插件）。
