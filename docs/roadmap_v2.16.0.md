# v2.16.0 Roadmap（安全与市场生态）

> 基线版本：v2.15.1
> 状态：规划中

---

## 一、主题目标

v2.16.0 聚焦三件事：

1. **插件市场从只读目录走向可用安装**（非对称签名 + 安装 UI）；
2. **安全工程常态化**（RPC 审计基线、签名密钥管理、表达式白名单）；
3. **体验收尾**（跨屏 DPI 验证清单、沙箱诊断 UI 打磨、CI 性能门禁自适应分片）。

---

## 二、P1（v2.16.0 必做）

### 1. Ed25519 非对称签名（✅ 已实现：公钥配置/轮换/吊销）
- 注册表提供公钥；插件包签名用私钥（离线工具签发）；
- 安装前验签：`cryptography` 可用时优先 Ed25519，否则回退 HMAC；
- 公钥可配置（`QINGCAO_PLUGIN_PUBKEY` 或设置项），并支持轮换/吊销清单。

### 2. 插件市场在线安装 UI（✅ 签名状态展示已实现）
- 市场对话框：分类筛选、详情页（版本/许可/权限/主页）、安装进度、来源标识；
- 签名状态展示（未签名/校验通过/校验失败/密钥缺失）；
- 安装完成后提示重启/重载插件。

### 3. 安全工程常态化（✅ 审计基线已实现）
- `tools/audit_sandbox_rpc.py --json` 输出基线并版本化（`tools/baselines/sandbox_rpc.json`）；
- CI 比对基线：白名单变更必须有基线更新提交；
- python_debugger 表达式白名单可配置（受限模式/开发者模式）。

## 三、P2（v2.16.x）

- 跨屏 DPI 真机验证清单 + 单机多屏缩放因子模拟增强；
- 沙箱诊断 UI：点击诊断跳转编辑器行列、按插件来源分组折叠（✅ 来源过滤已实现）；
- 性能门禁分片数自适应（按 CPU 数/负载选择 2~4 片）；
- 广播 ACK 语义完善（config/file 事件确认与重试）。

## 四、P3（中长期）

- 插件市场密钥轮换/吊销流程与文档（✅ 工具+手册已实现）；
- 主题/插件面板全量 E2E 截图回归（多主题基线）（✅ 工具+基线已实现）；
- 插件沙箱迁移扩展（更多只读插件）（✅ whitespace_sandbox 试点）；

## 五、验收标准

- 分片并行全量测试通过、ruff 0；
- 审计基线在 CI 生效且无未授权白名单变更；
- 市场安装：签名校验通过/失败路径均有测试覆盖；
- 无 P0 回归（多实例/主题/沙箱/发布流水线）。

## 六、风险与依赖

- Ed25519 依赖 `cryptography`（若不可用需回退方案）；
- 在线安装 UI 需要可用的注册表/下载源（离线目录 MVP 已具备兜底）；
- 跨屏 DPI 仍受单机硬件限制（只能模拟 + 真机清单）。
