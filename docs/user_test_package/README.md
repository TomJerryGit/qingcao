# 用户测试执行包（5 分钟上手 / Lite 版）

## 适用版本

- v2.26.41 或下一次 Lite 稳定版；
- Windows 10/11；
- 默认 Lite 模式（市场/评分入口隐藏）。

## 文件

| 文件 | 用途 |
|---|---|
| `01_invitation.md` | 招募文案（短版/长版） |
| `02_consent.md` | 参与者知情同意 |
| `03_facilitator_guide.md` | 主持人执行指南 |
| `04_task_script.md` | 15 分钟任务脚本 |
| `05_record_template.csv` | 单人记录表 |
| `06_analysis_template.md` | 汇总与优先级模板 |
| `07_followup.md` | 感谢与后续反馈 |

## 流程

1. 发招募文案 → 约 5–10 人；
2. 测试前读同意书；
3. 按任务脚本执行，主持人只记录不指导；
4. 每个用户填一行 CSV；
5. 用分析模板汇总 P0/P1/P2；
6. 只修阻断点，写入下一版计划。

## 原则

- 不录屏也可以；
- 不收集文件内容/路径/身份；
- 不诱导用户说“好用”；
- 真实记录失败与卡住的位置。
