# 主持人执行指南

## 测试前

- 关闭自己的编辑器实例，使用干净安装/解压目录；
- 准备计时器、记录表；
- 确认网络可用（AI 任务可选，不强制）。

## 原则

1. **不教操作**：用户卡住时先等 60 秒；
2. **只记录原话与位置**，不替用户解释；
3. 超过 2 分钟无进展可跳过，标记 P0；
4. 不评价“这个很简单”；
5. 每个任务记录：完成/未完成、用时、阻断点。

## 结束

- 问 3 个问题：
  1. 最卡的一步是什么？
  2. 明天还会用吗？为什么？
  3. 最想删掉/保留的功能？
- 感谢并说明后续不会频繁打扰。

## 禁止

- 代填记录；
- 用维护者体验冒充用户数据；
- 收集与测试无关的个人信息。
