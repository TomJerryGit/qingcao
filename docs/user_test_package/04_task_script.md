# 任务脚本（约 15 分钟）

> 给参与者：请按自己的理解操作，遇到卡住直接说，不用怕操作错。

## 任务 1：安装与首次启动（2 分钟）

- 安装/解压并启动；
- 预期：出现首次启动向导；
- 记录：是否完成、是否卡住、是否跳过。

## 任务 2：打开示例并运行（2 分钟）

- 在欢迎页打开示例文件；
- 按 F5 运行；
- 预期：输出“Hello, QingCao!”；
- 记录：是否找到 F5、是否看到输出。

## 任务 3：修改并保存（2 分钟）

- 修改示例内容；
- 按 Ctrl+S 保存；
- 记录：是否知道保存方式、是否出现错误。

## 任务 4：全局搜索（2 分钟）

- 用 Ctrl+Shift+F 搜索一个词；
- 记录：是否找到入口、结果是否可读。

## 任务 5：切换主题（2 分钟）

- 视图 → 主题，切换一次；
- 记录：菜单是否易找、文字是否清晰。

## 任务 6：关闭重开（2 分钟）

- 关闭并重新打开；
- 预期：最近文件/会话可恢复；
- 记录：是否恢复、是否报错。

## 可选任务（有 AI Key 时）

- 打开 AI 助手，解释选中代码；
- 无 Key 可跳过，不计入完成率。
