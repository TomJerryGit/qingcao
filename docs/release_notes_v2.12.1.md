## 新增 / 改进

### spell_check 沙箱桥接（P1）

- spell_check 重新标记 `sandbox: true`，菜单/状态栏能力经宿主代理：
  - `menu_items()`：「忽略本文件可疑词」「重新加载忽略词」
  - `invoke_menu(id)`：调用成功宿主自动重跑诊断
  - `status_text()`：状态栏显示「拼写: N 条 / 就绪」
- **插件配置变更广播**：任一实例保存配置后广播 `config_changed`，
  其它实例自动重新读取并下发配置、重跑诊断。

### 大文件跳过实时诊断（P2）

- 实时沙箱诊断阈值 **5 MB**：超过自动跳过并在状态栏提示（只提示一次），
  回到小文件自动恢复，避免大文件卡顿。
- 主题性能门禁：`theme_reapply` 阈值纳入 CI 性能检查，
  主题切换回归会被拦截。

### CI 与发布（P3）

- 测试分片**并行执行**（`--parallel`），2 片实测 269.7s 全部通过；
- Release 正文自动追加「变更摘要（自动生成）」——从 CHANGELOG 提取当前版本条目。
