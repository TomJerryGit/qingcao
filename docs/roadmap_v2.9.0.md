## v2.9.0 候选（按优先级）

### P0 多实例事件补全

- 广播「打开/关闭文件」事件：多实例下状态更一致；
- 冲突保护：同一文件被两个实例同时修改时提示风险；
- 广播协议加版本号，向后兼容旧实例。

### P1 沙箱能力补全

- 沙箱支持 `add_menu`/`add_status_item` 的宿主代理（受限白名单），
  让 spell_check 完全沙箱化后仍保留菜单/状态栏能力；
- 沙箱插件配置读写代理（宿主校验 JSON schema）。

### P2 真机验证清单

- 双显示器 / 跨屏 DPI 变化的手工验证步骤文档化；
- 高对比度主题 + Windows 高对比度模式兼容检查。

### P3 发布质量

- GitHub Release 自动附加 `release_notes` 与体积变化报告；
- Runner 服务化方案（需要管理员账户凭据；否则保留 Startup 自启）。
