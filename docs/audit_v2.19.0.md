## 一、结论摘要

| 级别 | 项 | 说明 |
|---|---|---|
| **中** | 新功能无 UI 入口（mmap / Token / 诊断阈值 / 大文件阈值） | 只能改环境变量或 QSettings，普通用户不可发现/配置 |
| **中** | F5 快捷键重复绑定 | 「运行当前文件」在「特色功能」和「工具」菜单各注册一次，Qt 会出现快捷键歧义 |
| **低** | 特色功能菜单禁用占位项 | AI 助手 / Git 插件未启用时显示「该插件未注册命令，或未启用」 |
| **低** | i18n 脚手架未接线 | 已提取 5218 条中文串，但无语言菜单/开关，`tr()` 未被 UI 调用（与 v2.19 P1 计划一致） |
| **低** | 设置键文档化不足 | 27 个键无 GUI 写入（多数为内部/兼容键，但 `mmap_incremental_save`、`registry_token`、`live_diagnostics_max_mb`、`large_file_threshold` 属真实缺口） |
| ✅ | 菜单接线完整 | 170 个叶子动作 **0 个无接收器**（无死菜单） |
| ✅ | 发布链一致 | version 2.18.1 = CHANGELOG [2.18.1] = Release；Unreleased 为 v2.19 内容 |

## 二、菜单完整性

- 顶级菜单 14 个：文件/项目/编辑/特色功能/视图/工具/搜索/宏/运行/窗口/编码/语言/设置/帮助；
- 叶子动作 170 个，全部有 Qt 接收器（无「点了没反应」的菜单项）；
- 快捷键覆盖：约 54 个（键盘审计工具 `tools/audit_keyboard_a11y.py` 口径）；
- **重复快捷键 1 组**：

| 快捷键 | 冲突动作 |
|---|---|
| `F5` | 菜单/⭐ 特色功能/▶ 运行当前文件 ↔ 菜单/工具(T)/▶ 运行当前文件 |

- 禁用动作 3 个：最近项目占位（正常）、AI 助手/Git 插件未启用占位（插件未装时出现）。

## 三、设置入口缺口（已核实）

以下键**有代码读取，无任何 GUI 写入**：

| 键 | 影响 | 建议 |
|---|---|---|
| `mmap_incremental_save` | v2.19 M1 增量保存无法在界面开启（灰度仅环境变量） | 设置 → 编辑器 增加开关（默认关） |
| `registry_token` | 市场 Token 鉴权无法配置 | 插件市场 → 注册表设置增加 Token 输入（密码框） |
| `live_diagnostics_max_mb` | 实时诊断大文件阈值不可调 | 设置 → 高级 增加 1~512MB 数值 |
| `large_file_threshold` | 大纲面板大文件阈值仅代码默认 | 设置 → 编辑器 增加阈值 |

另：`plugin_hot_reload` 等键有 Preferences 属性但界面入口需核查（可能在其他设置页模块）。

## 四、功能实现 vs 文档

- README 特性行 49 条，主要功能（多光标/列模式/LSP/问题/大纲/主题市场/插件市场/沙箱/宏/AI）均能在菜单或设置中找到入口；
- **无「终端」功能实现**（README/roadmap 未承诺，若未来规划需新增面板 + 菜单）；
- i18n：`locale/zh_CN/strings.json`（5218 条）+ `core/i18n_json.py` 已就绪，但 `tr()` 未被 UI 调用 → 属 v2.19 P1-2 计划内工作；
- mmap：`core/mmap_save.py` 仅 `Document.save` 接入（3 处引用），符合 M1 范围；**无 UI、无 journal 管理界面**。

## 五、代码与工程健康

- 测试 123 个文件；工具 85 个；ruff check / format 全绿；
- TODO/FIXME/占位 标记约 159 处（含注释中的经验说明，非全部缺陷）；
- 硬编码 `D:\actions-runner` 仅出现在 2 个 CI 工具（`analyze_crash_dumps.py`、`enable_crash_dumps.py`），属环境专用，可接受但建议参数化；
- 兼容残留：`MAX_LIVE_DIAGNOSTICS_BYTES` 类属性保留（fallback），实际阈值已走 `_live_diag_limit()`，无死锁风险。

## 六、建议修复优先级（v2.19.0）

1. **P1**：F5 重复绑定去重（删除「特色功能」中的重复项或改为不同快捷键）；
2. **P1**：mmap / Token / 诊断阈值 / 大文件阈值 四项设置 UI（中等工作量）；
3. **P2**：插件未启用时隐藏「特色功能」占位项（或改为「启用插件」引导）；
4. **P2**：i18n UI（v2.19 P1-2 计划）；
5. **P3**：硬编码 CI 路径参数化。
