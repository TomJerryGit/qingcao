# 青草编辑器 v2.13.0 发布说明

> 发布日期：2026-10-28 · 平台：Windows x64 · 便携版（免安装）
> 版本权威来源：`version.py`（`2.13.0`）
> 功能版本：包含 v2.12.1 全部内容。

---

## 一句话概括

v2.13.0 加入**高对比度自动适配**（含面板 QSS 让位系统配色），
增强多实例配置同步反馈与实例上限可配置，并落地真机验证体系。

---

## 新增 / 改进

### 高对比度自动适配（无障碍）

- 启动检测 Windows 高对比度：开启时自动应用**系统调色板 QSS**；
- HC 模式下**抑制面板自定义 QSS**，让系统配色真正生效；
- 关闭 HC / 关闭开关后**完整恢复**原主题与面板样式；
- 工具菜单「♿ 跟随系统高对比度」勾选项（默认开启，持久化）。

### 多实例体验增强

- **配置变更广播 UI**：收到其它实例配置变更时状态栏提示
  「配置已同步（来自其它实例）· 已刷新菜单/诊断」；
- **实例上限可配置**：`QINGCAO_MAX_INSTANCES` 环境变量或
  `QSettings.max_new_window_instances`（1~10，默认 3）；
- **崩溃草稿清理工具**：`tools/clean_recovery_drafts.py`
  （默认预览，`--yes` 移动到 `data/_trash_<日期>/`）。

### 验证体系

- `tools/simulate_high_contrast.py`：高对比度开关/状态（`--yes` 确认，自动恢复）；
- 真机验证报告与截图：`docs/validation_results_v2.13.md`；
- 单机可模拟项：高对比度、全局/多屏缩放因子；跨屏拖动需真实双屏。

## 升级注意事项

1. v2.12.1 → v2.13.0 无数据迁移；
2. 高对比度模式下面板应用内精致样式会让位系统配色（属预期取舍）；
3. 实例上限如需调整：设置 `QINGCAO_MAX_INSTANCES` 或对应 QSettings 键。
