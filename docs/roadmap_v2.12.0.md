## v2.12.0 候选（按优先级）

### P0 多实例冲突检测

- 保存广播增加冲突判定：远端保存时本地有未保存修改 → 明确警告并
  提供「保留本地/重载」选择（当前只询问是否重载）；
- 打开/关闭事件的重复抑制（相同路径多次打开）。

### P1 沙箱能力继续下沉

- spell_check 的**右键菜单**与**状态栏**全部走宿主代理；
- 沙箱插件配置变更广播到其它实例（多实例一致性）。

### P2 性能与体验

- 实时沙箱诊断在大文件（>5MB）自动降级（防卡顿）；
- 主题切换覆盖独立对话框后的回归基准纳入 performance gate。

### P3 工程

- CI 分片并行（若 Runner 增加核数/多 runner）；
- Release 自动附加「相对上一版体积变化」已在 v2.11.x 完成，
  下一版可加「变更摘要自动生成」。
