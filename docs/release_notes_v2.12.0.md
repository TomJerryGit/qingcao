# 青草编辑器 v2.12.0 发布说明

> 发布日期：2026-10-28 · 平台：Windows x64 · 便携版（免安装）
> 版本权威来源：`version.py`（`2.12.0`）
> 功能版本：包含 v2.11.3 全部内容。

---

## 一句话概括

v2.12.0 强化多实例安全与协作：保存冲突检测、单实例聚焦、
`--new-window` 实例上限，修复误开大量实例导致机器卡死的问题；
同时隔离测试会话/QSettings，消除顺序敏感 flaky。

---

## 新增 / 改进

### 多实例冲突检测

- 其它实例保存同一文件且本地有**未保存修改**时，弹出「保存冲突」对话框：
  - 默认「保留本地修改」（并提示冲突未解决）；
  - 可显式选择「重新加载磁盘内容」；
- 冲突信息记录于 `_last_remote_conflict` 便于排查；
- 修复 `Document.is_modified` 为 property 导致冲突判断被异常吞掉的问题。

### 实例数量保护（防卡死）

- **单实例聚焦**：普通启动（无 `--new-window`）会先通知已运行实例聚焦窗口
  并退出，不再重复创建进程；
- **`--new-window` 上限 3**：超过时提示并安全退出；
- 启动时自动清理已退出实例的陈旧配置目录（PID 存活检测）。

### 打开事件重复抑制

- 同一文件路径只广播一次 `file_opened`，避免多实例间事件放大。

### 测试稳定性

- 测试会话文件通过 `QINGCAO_SESSION_FILE` 隔离到临时目录；
- `test_default_panels_visible` 自清理继承的窗口/会话布局状态；
- 分片工具对「无测试文件」（pytest rc=5）按跳过处理。

## 升级注意事项

1. v2.11.3 → v2.12.0 无数据迁移；
2. 普通启动默认复用已运行实例（如需并行编辑请显式 `--new-window`，最多 3 个）；
3. 冲突时请留意「保留本地」的提示，避免覆盖对方修改。
