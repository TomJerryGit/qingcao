## 三、P1（v2.21.0 必做）

### 1. 终端 MVP 实现（✅ 已落地：QProcess 面板）
- 面板：底部 dock `TerminalPanel`（QProcess + 只读输出 + 输入行）；
- Shell：Windows PowerShell（默认）/cmd 可切换；工作目录 = 项目根或文件目录；
- 菜单：视图 → 面板 → 终端；可配置快捷键（默认 Ctrl+`）；
- 主题适配；关闭/崩溃时 terminate→kill，防僵尸进程；
- 安全：不自动执行命令、不落盘命令历史（可选开关）；
- 验收：启动、回显命令、清屏、复制、关闭清理、主题适配测试；文档更新。

### 2. 多语言（第二批：繁体中文）（✅ 已落地：5227 条/100% 门禁）
- 以 `locale/zh_CN/strings.json`（5218）为源，生成 `locale/zh_TW/strings.json`
  （简繁转换 + 术语校对，优先可翻译语料 597）；
- 语言菜单新增「繁體中文」；
- 覆盖率/QA 门禁按语言分别检查（zh_TW 语料覆盖 100%）；
- 验收：繁中界面可用；术语与 `i18n_glossary.md` 一致；CI 通过。

### 3. 市场公网化（GitHub Releases 静态托管）（✅ 发布工具/工作流/客户端常量已落地，待真实密钥发布）
- `tools/publish_registry_release.py`：构建 registry.json + 插件 zip，
  签名后上传到专用 Release（tag 如 `plugin-registry`）；
- 客户端注册表 URL 指向
  `https://github.com/TomJerryGit/qingcao/releases/download/plugin-registry/registry.json`；
- CI 工作流（手动触发或 tag）执行发布；公钥沿用现有机制；
- 文档：`docs/plugin_registry_github_releases.md`（发布/回滚/公钥分发）；
- 验收：公网 URL 可拉取；在线安装闭环；篡改拒绝；断网回退。

## 六、验收标准（v2.21.0）
- 分片并行全量测试通过、ruff 0、CI 全绿；
- 终端 MVP 可用（含清理与主题测试）；
- 繁中界面覆盖率 100%（可翻译语料）；
- GitHub Releases 注册表可公网拉取并完成安装；
- 无 P0 回归（发布/多实例/主题/沙箱）。

## 七、风险与依赖

| 风险 | 缓解 |
|---|---|
| 终端进程泄漏/安全 | 显式输入 + terminate/kill + 超时清理 |
| 繁中术语不一致 | 复用英文术语表思路 + 繁中术语表 |
| GitHub Releases 资产大小/配额 | 插件包小、按需发布；保留本地/内网回退 |
| 公网访问稳定性 | 客户端现有 CDN/缓存/离线回退兜底 |
