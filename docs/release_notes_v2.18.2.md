# 青草编辑器 v2.18.2 发布说明

> 发布日期：2026-11-03 · 平台：Windows x64 · 便携版（免安装）
> 版本权威来源：`version.py`（`2.18.2`）
> 类型：补丁版（主题菜单 + 设置 UI + 菜单体验 + CI）

---

## 修复

### 主题菜单（重要）
- v2.18 拆分 Mixin 后主题目录路径错误（`ui/themes`），导致托盘菜单只显示「跟随系统」；
- 修复后内置主题（暗夜/护眼/高对比/明亮）全部恢复。

### 设置 UI（审计缺口补齐）
| 位置 | 新增 |
|---|---|
| 设置 → 编辑器 → 保存 | mmap 增量保存（实验，默认关）+ 大文件阈值 1~512MB |
| 设置 → 高级 → 性能与诊断 | 实时沙箱诊断大文件阈值 1~512MB |
| 插件市场工具栏 | 访问令牌（Bearer，密码框）+ 校验 TLS 证书 |

### 特色功能菜单
- 插件未启用/未注册命令时**隐藏** AI/Git 子菜单（不再显示灰色占位项）；
- 插件延后加载注册命令后自动显示；禁用后自动隐藏。

## 升级注意事项

1. v2.18.1 → v2.18.2 无数据迁移；
2. mmap 增量保存为**实验功能**，默认关闭，仅等长修改生效，失败自动回退全量保存；
3. 市场 Token/TLS 配置仅对配置了鉴权的注册表生效。
