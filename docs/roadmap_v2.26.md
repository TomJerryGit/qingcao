# 青草编辑器 v2.26+ 开发/优化/测试路线图（2026-11-12 修订）

> 基线：v2.25.0（审计 8.6/10，HEAD 81659d1 之后）· **证书决策：不再申请 Authenticode，发布完整性继续使用 SHA256 + Ed25519 `.sig`**

## 决策与范围

| 事项 | 决定 |
|---|---|
| Authenticode 证书 | **关闭**（不采购/不申请）；`release.yml` 条件步骤保留为 no-op，文档标记“已决策不启用” |
| 发布完整性 | SHA256 + Ed25519 签名（含密钥轮换能力）保持不变 |
| v2.25.1 | **优先发布**，固化沙箱 B1.5/看板/密钥轮换/macOS spike |
| 主线 | 沙箱 B2/全量灰度 → 架构长尾 → flaky/CI → macOS/MVP → 生态 |

## 风险与依赖

| 风险 | 缓解 |
|---|---|
| 沙箱 all 模式兼容性 | 逐插件灰度 + feature flag 回退（进程内） |
| flaky 难复现 | crash_triage + 固定复现环境 |
| CI 单 runner | 托管 Windows 兜底常态化；仍不足则申请第二 runner |
| macOS 维护成本 | 先 MVP 决策门，不默认承诺 |
| 证书关闭影响 | 不阻塞发布；仅 SmartScreen 提示，文档说明 |
