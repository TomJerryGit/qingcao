## 二、P0：v2.23.0（下一版，建议 2 周）

### 1. 巨石文件拆分（架构 + 质量，最高收益）
| 文件 | 现状 | 目标 | 拆分方案 |
|---|---|---|---|
| `core/editor.py` | 3,920 行 | ≤1,500 | `editor_core.py`（文本/光标）、`editor_syntax.py`（高亮/折叠）、`editor_save.py`（保存/mmap 接线）、`editor_diag.py`（诊断/LSP） |
| `ui/main_window.py` | 3,267 行 | ≤1,200 | 菜单→`menu_builder_mixin`（已部分）、面板→`panel_registry_mixin`、窗口生命周期→`window_lifecycle_mixin`、初始化→`startup_mixin` |
| `ui/plugin_store.py` | 2,963 行 | ≤1,500 | `plugin_client.py`（网络/缓存/签名）、`plugin_detail.py`（详情/评分 UI）、`plugin_store.py`（列表/安装/更新） |
| `app/plugins.py` | 2,553 → **217 行** ✅ | ≤1,200 | PluginAPI → `app/plugin_api.py`（2109） |
| `infrastructure/theme_loader.py` | 2,355 → **1,314 行** ✅ | ≤1,200 | 模型/内置主题 → `theme_model.py`（828） |

**验收**：拆分后单文件行数达标；对外 API 不变；全量测试绿；新增拆分模块边界测试；性能无回归。
**风险**：Mixin 方法引用链断裂 → 先加"符号引用"测试，分文件提交，每步跑全量。

### 2. 终端 PTY（功能，用户可感知）（✅ UI 集成 MVP 已完成）
- 引入 `pywinpty`（Windows）与 `pty`（Unix）抽象；
- 交互式 shell：持续会话、stdin/stdout、Ctrl+C、窗口大小；
- 保留多标签/ANSI/历史；新增命令补全（路径/历史）；
- 安全：默认不自动执行，关闭时 terminate/kill。
**验收**：`python -i` 交互可用；Ctrl+C 中断；多标签独立会话；关闭无残留进程；测试覆盖启动/输入/中断/清理。
**工作量**：5–7 人日（依赖引入与打包验证 1–2 天）。

### 3. Flaky 专项（测试质量）
- 原生 Qt 崩溃 dump 自动命名测试文件/阶段（崩溃面包屑）；
- fallback 频率纳入发布门禁：连续 3 次 → 降并行/隔离可疑文件；
- 每周 `ci_flaky_report` 复盘；保留 2 片并行作为默认。
**验收**：连续 10 次全量无"无法定位"的 flaky；报告含可疑文件 Top5。

### 4. 反馈闭环（用户体验）
- 冒烟清单内置到反馈对话框（可勾选"已体验终端/语言/市场"）；
- 每版发布后固定收集 ≥3 条真实反馈；反馈报告进入版本评审。
**验收**：v2.23.0 发布后 1 周内获得 ≥3 条真实反馈并分诊。

## 三、P1：v2.23.x（2–3 周）

### 5. 插件市场增强（生态）（静态评分聚合 MVP ✅）
- **静态评分聚合**：`ratings.json` 随 registry 发布（本地评分可选上送/手动导出合并），零服务端；
- **下载统计**：GitHub Release 资产下载量 API 聚合（无需自建服务）；
- 市场**搜索/分类/标签筛选**（本地过滤增强）；
- 评分服务端草案演进为只读聚合（`docs/plugin_rating_server_draft.md` 阶段 1）。
**验收**：市场可搜索/筛选；评分聚合展示平均分与来源；不破坏签名校验。

### 6. 日韩长尾翻译（i18n）
- ja_JP/ko_KR 从 43 条扩到 **150+ 条**（核心 UI 全覆盖）；
- 覆盖率门禁从 3% 提升到 15%；
- 术语表补充日/韩对照。
**验收**：覆盖率 ≥15%；日/韩界面核心路径无中文残留（允许长尾）。

### 7. 跨平台构建（发布工程）
- Linux AppImage 构建（Ubuntu runner + PyInstaller）；
- Windows 构建保持；macOS 评估（无签名分发方案）。
**验收**：CI 产出 Linux AppImage；启动冒烟通过；发布说明标注平台。

## 四、P2：v2.24.0（3–4 周）

### 8. 性能专项
- 50MB 文件打开从 4.35s 优化（mmap 读取/高亮分块/懒渲染）；
- 启动时间目标 ≤1.5s；
- 面板懒加载与事件节流回归基线。
**验收**：open_50mb ≤3.0s、startup ≤1.5s；性能门禁通过。

### 9. mmap 默认开启决策
- 基于改进后埋点（target 字段）收集 2 周真实保存数据；
- 若回退率 <5% 且样本 ≥20 → 默认开启（保留开关与回退）；
- 否则继续灰度并出数据报告。

### 10. 无障碍深化
- NVDA 实际验证 + 高对比度 4 主题回归；
- 键盘全路径覆盖（面板/对话框/评分）。

### 11. 更新通道
- 稳定版/预览版双通道（GitHub Releases tag 约定）；
- 更新检查支持通道选择；失败降级不影响启动。
