## 二、根因分析（审计证据）

### 功能完整度（8.3）
- 终端 PTY 为**行模式**（输入整行发送），非全屏/原始交互终端；
- 无 macOS 支持；市场无搜索/分类筛选（仅基础过滤）；
- 评分聚合已实现但**未上线**（注册表未重发）；无下载统计；
- 无插件 SDK/模板，第三方开发门槛高。

### 架构设计（8.0）
- 拆分后仍有 9 个 >2,000 行文件（ai_assistant 3,258、plugin_api 2,294、editor_view 2,235、tabs 2,219、content_provider 2,190、document 2,072、editor 2,028、outline_panel 2,024、session 2,010）；
- 缺少**依赖方向约束**（core 不应依赖 ui/app，插件 API 与 UI 耦合）；
- 事件总线/服务定位无接口抽象，可测试性一般。

### 代码质量（7.5）
- 非测试代码 `except Exception:` **1,488 处**，关键路径错误被吞；
- 无静态类型门禁（mypy/pyright）、无覆盖率统计；
- 存在 0 调用点函数与孤立模块（audit_stubs/orphan 报告）；
- 文档与实现部分漂移（138 份 docs）。

### 性能工程（7.5）
- `open_50mb` **4.35s**（目标 3.0s）；性能门禁最低有效容差 **5×**，几乎不拦截退化；
- 大文件仍全量高亮/渲染路径；启动 1.8s（目标 1.5s）；
- 缺少内存与首屏时间的持续趋势。

### 安全性（7.8）
- 高权限插件（process/eval）**in-process 运行**，依赖权限提示；
- 安装包/更新包**未签名**（插件包有 Ed25519）；
- ratings.json 无签名；依赖无漏洞扫描（pip-audit）；
- CI Actions 仅按 tag 引用（建议 pin SHA）。

### 用户体验（7.5）
- 功能入口多、发现性差（178 菜单项，快捷键覆盖 30.9%）；
- 设置项多、缺少基础/高级分层；
- 首启无引导；错误提示技术化；
- 语言切换需重启；真实反馈样本少（6 条）。

### 生态与扩展（7.2）
- 13 个插件、无 SDK/模板/API 版本承诺；
- 市场无服务端评分/下载统计/搜索；
- 插件质量与安全分级未在 UI 呈现。

## 三、工作流与验收标准

### W1 架构：第二轮拆分 + 依赖治理
**动作**
1. 拆分 `plugins/ai_assistant/__init__.py`（3258）→ `ai_client.py` / `ai_ui.py` / `ai_actions.py`；
2. 拆分 `app/plugin_api.py`（2294）→ `plugin_api_core.py` / `plugin_api_editor.py` / `plugin_api_ui.py`（按权限域）；
3. 拆分 `ui/editor_view.py`（2235）→ 视图/输入/高亮/事件；
4. 拆分 `app/tabs.py`（2219）、`core/content_provider.py`（2190）、`core/document.py`（2072）、`app/session.py`（2010）；
5. 建立**依赖规则**（core 不 import ui/app；插件 API 不 import 具体 UI 对话框），用 `tools/audit_dependencies.py` 门禁；
6. 单文件上限 1,500 行（CI 门禁，超标白名单逐步清零）。

**验收**：无 >1,500 行文件（或白名单 ≤3）；依赖审计 0 违规；全量测试绿。

### W2 代码质量：异常治理 + 类型 + 覆盖率
**动作**
1. **异常收窄**：`core/`、`app/session`、`app/tabs` 关键路径禁止裸 `except Exception`（改为具体异常 + 日志），CI 增量门禁；
2. 引入 **mypy（宽松模式）** 对 `core/` 与 `infrastructure/` 增量检查；
3. **覆盖率**：pytest-cov 统计 core 包，目标 ≥70%，CI 报告（不强制全仓）；
4. 清理 audit_stubs/orphan 的 0 调用代码（保留公共 API 白名单）；
5. 日志规范：异常必须带上下文（模块/操作/对象）。

**验收**：关键路径宽泛异常 0；mypy 无新增错误；core 覆盖率 ≥70%；stubs 清理完成。

### W3 性能：大文件与门禁（✅ 门禁收紧 + 视口原型完成）
**动作**
1. 50MB 打开专项：**视口渲染/分块高亮**（只高亮可见行）、延迟符号解析、按需缩略图；
2. 启动优化：插件/面板懒加载进一步延迟到首屏后；
3. 性能门禁：`--auto` 有效容差 5× → **2×**；open_50mb 单独硬阈值 3.0s；
4. 相对回归门禁：较上次基线 >20% 失败；
5. 内存峰值与首屏耗时纳入趋势。

**验收**：open_50mb ≤3.0s、startup ≤1.5s；门禁可拦截 2× 退化；趋势无连续回归。

### W4 安全：沙箱强制 + 签名闭环
**动作**
1. `process/filesystem/network` 高权限插件**强制沙箱**（或在安装向导中显式风险分级 + 二次确认）；
2. 安装包/更新包 **Ed25519 签名** + 客户端校验；
3. ratings.json 签名（防篡改）；
4. CI 增加 `pip-audit` 依赖漏洞扫描；GitHub Actions pin 到 SHA；
5. 插件权限测试矩阵（越权用例）。

**验收**：高权限插件默认沙箱；更新/评分资产签名校验；pip-audit 0 high；Actions 全 pin。

### W5 用户体验：发现性与引导
**动作**
1. 首启向导（3 步：语言/主题/插件市场）；
2. 命令面板强化：全部命令可搜、最近使用置顶；
3. 设置分层：基础（常用 10 项）/ 高级（折叠）；
4. 快捷键覆盖 30.9% → ≥50%；菜单图标统一；
5. 错误提示标准化（原因 + 下一步动作）；
6. 语言切换免重启（动态刷新 UI 文案）；
7. 每版发布说明内嵌反馈入口，收集 ≥3 条真实反馈。

**验收**：首启完成率可测；设置页减少 40% 首屏项；快捷键覆盖 ≥50%；重启切换语言为可选。

### W6 功能：终端/市场/平台
**动作**
1. 终端全屏原始模式（alt-screen、光标定位、raw PTY）——在行模式基础上增加；
2. 市场：搜索/分类/标签筛选 + 下载统计 + 社区评分展示；
3. macOS 评估（GitHub Actions runner 构建可行性）；
4. 会话恢复增强（崩溃后恢复最近编辑）。

**验收**：`vim`/`top` 可在终端运行；市场可搜索；评分/下载可用；平台评估报告。

### W7 生态：SDK 与服务端
**动作**
1. `plugin-template/` 仓库内模板 + 开发文档 + 本地调试命令；
2. 插件 API **semver 兼容承诺** + 弃用策略；
3. 评分服务端阶段 2（只写服务 + 反滥用 + 隐私政策）；
4. 插件质量徽章（官方/社区/沙箱/签名）；
5. 目标插件数 20+。

**验收**：新插件 30 分钟可跑通；API 文档完整；评分服务端灰度；徽章展示。

### W8 i18n：日韩正式化
**动作**
1. key 驱动翻译至 **50%**（ja/ko）；
2. zh_TW 术语终审；语言切换免重启（与 W5 联动）；
3. CI 门禁 15%→50%。

**验收**：ja/ko 50%；核心路径无中文残留；门禁生效。

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| 拆分引入回归 | 每步小提交 + 全量测试 + re-export 兼容 |
| 性能优化收益不确定 | 先做原型（视口渲染）再全量；保留旧路径开关 |
