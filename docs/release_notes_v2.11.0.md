# 青草编辑器 v2.11.0 发布说明

> 发布日期：2026-10-27 · 平台：Windows x64 · 便携版（免安装）
> 版本权威来源：`version.py`（`2.11.0`）
> 功能版本：包含 v2.10.0 全部内容。

---

## 一句话概括

v2.11.0 让沙箱插件配置**即时生效**、支持**实时诊断**，修复 125% 缩放下的
窗口销毁崩溃，并增强发布报告与 CI 兼容性验证。

---

## 新增 / 改进

### 沙箱配置热更新（P0）

- 插件设置保存后无需重启：写入 QSettings → 立即 `config_apply` 下发 →
  **自动重跑沙箱诊断** → 刷新插件菜单；
- 状态栏提示「已保存并即时生效」。

### 实时沙箱诊断（P1）

- 工具菜单「⚡ 实时沙箱诊断（停止输入 500ms）」可勾选开关（默认关闭）；
- 编辑停止输入 500ms 后自动运行沙箱诊断并发布到问题面板；
- 500ms 防抖，避免高频子进程调用。

### 125% 缩放崩溃修复（P2）

- 根因：主题事件过滤器挂在 QApplication 上，窗口销毁时未移除，
  多窗口/多测试连续创建时访问已销毁对象（0xC0000005）；
- 修复：`closeEvent` 显式移除过滤器 + `sip.isdeleted` 防御；
- 验证：125% 缩放合跑连续 3 次通过，150% 与正常缩放全量测试通过；
- 新增 `tools/verify_display_env.py` 显示环境自检与
  `docs/manual_validation_v2.10.md` 真机验证清单。

### 发布质量与 CI（P3）

- Release 正文自动附加「较上一版体积变化」（MB / 百分比）；
- CI 新增 Python 3.12 **软矩阵** job：解释器缺失自动跳过，
  不阻塞主门禁（主门禁仍为 Python 3.11）。

## 升级注意事项

1. v2.10.0 → v2.11.0 无数据迁移、无接口破坏；
2. 实时诊断默认关闭，可在工具菜单开启；
3. 沙箱插件需实现 `config_schema()`/`on_config()` 才支持热更新。
