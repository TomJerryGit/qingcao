## 一、实时协作（`core/collab.py` 235 行 + `ui/collab_dialog.py` 231 行）

### 实测事实

| 项 | 现状 |
|---|---|
| 协议 | **裸 TCP**（`socket.socket(AF_INET, SOCK_STREAM)`） |
| 监听 | `server.bind(('0.0.0.0', 52000))` —— **监听所有网卡** |
| 加入 | `sock.connect((host, port))`，按 host/port/room 连接 |
| 加密 | **无**（明文 TCP） |
| 认证 | **无**（任何人连上即可加入） |
| NAT 穿透 | **无**（仅同局域网/公网直连可达） |
| 冲突解决 | 有 Insert/Delete/Replace 命令（`CollabSession`） |
| UI | 完整：启动主机 / 加入 / 离开 / 关闭 + 主机地址/端口/房间名 |

### 缺什么（按优先级）

1. **安全模型** —— 当前形态相当于"在局域网开放一个无密码的共享编辑端口"。
   * 需要：房间密码或邀请令牌、连接白名单、至少 TLS 或端到端加密；
   * 否则**不建议**默认开启，也不建议写进"推荐功能"。
2. **可达性** —— 真实用户多数不在同一局域网。
   * 选项：中继服务器（成本）/ WebRTC（复杂度高）/ 仅限局域网（明确声明）。
3. **冲突语义** —— 需要定义"两人同时改同一行"的确定性结果与提示。
4. **验证环境** —— 本会话无网络可用，**无法做真实的双端联调**。
   只能验证到"协议消息能编解码、UI 能构造"。

### 三个可选方向

| 方向 | 工作量 | 风险 | 适用 |
|---|---|---|---|
| **A. 只做局域网演示** | 1~2 天（加密码 + 明确提示"仅局域网"） | 中 | 内部演示/教学 |
| **B. 加中继服务器** | 需服务端 + 运维 | 高（要运营） | 真产品 |
| **C. 保持现状/移除 UI** | 0.5 天删 UI | 低 | 不做该功能 |

**建议**：若不做真产品，选 **C**（删掉 UI，保留 `core/collab.py` 作参考），
或选 **A** 并**在 UI 上明确标注"仅局域网、无加密"** —— 绝不能让用户以为
这是一个安全的协作功能。

## 二、代码片段市场（`core/snippet_market.py` 133 行 + `ui/snippet_market_dialog.py` 222 行）

### 实测事实（关键）

```python
# core/snippet_market.py:13
MARKET_API = "https://api.github.com/repos/qingcao-editor/snippets/contents"
```

**这个仓库不存在** —— 已实测该地址返回 **HTTP 404 `{"message":"Not Found"}`**。
也就是说：即使把 UI 接上，用户点"刷新"只会拿到 404，
**列表永远是空的** —— 这不是"功能弱"，是**没有内容源**。

其他事实：

| 项 | 现状 |
|---|---|
| 依赖 | `requests`（已在 `requirements.txt` 里） |
| 流程 | `刷新` → GET GitHub contents API → 列表；`安装选中` → 下载文件到本地 |
| 语言筛选 | 对话框有"语言"下拉 + "搜索"框 |
| 内容 | **无**（API 指向不存在的仓库） |

### 缺什么

一个**真的内容源**。三种选项：

| 方向 | 工作量 | 说明 |
|---|---|---|
| **A. 建官方仓库** | 0.5 天（配置）+ 持续内容运营 | 把 `MARKET_API` 指向真实仓库；需要有人维护片段库 |
| **B. 改为"本地片段库导入"** | 1 天 | 去掉网络，改成从本地目录/压缩包导入 —— 零运维、零信任风险 |
| **C. 移除该功能** | 0.5 天 | 保留 `core/snippet_market.py` 或一并删 |

**建议**：**B**。理由：
* 网络市场需要长期运营（内容、审核、CDN、安全），超出本编辑器当前阶段；
* 而"本地片段库"已经有 `core/snippets.py`（片段功能本身是可用的），
  只需把市场 UI 改成"从本地目录导入"即可复用全部 UI 代码；
* 无网络请求 = 无信任风险（不会执行第三方下载的代码）。
