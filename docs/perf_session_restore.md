# 会话恢复成本测量（v2.25）

`tools/bench_session_restore.py` 实测（离屏）：

| 打开文件数 | restore 耗时 |
|---|---|
| 1 | 0.388s |
| 5 | 0.436s |
| 10 | 0.534s |
| 20 | 0.790s |

结论：
- **基线 0.388s 是空窗口构造**，会话恢复本身边际成本约 **20ms/文件**；
- 20 个文件仅比 1 个多 0.4s，**降低文件数上限收益有限**；
- 恢复已异步（200ms 后）执行，不阻塞首帧；
- 若需进一步优化，应针对单文件打开路径（内容加载/词法分析），而非文件数量。

配套：`tools/measure_first_paint.py` 可测首帧/绘制/Polish 次数（真实桌面人工观察用）。
