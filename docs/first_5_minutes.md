# 首次启动 5 分钟上手

## 目标

新用户完成安装后，5 分钟内完成一次“打开 → 编辑 → 运行 → 保存”。

## 流程

1. 首次启动向导：选择主题/常用插件 → 完成；
2. 自动打开 `data/samples/sample.py`；
3. 按 **F5**，运行控制台/调试器输出结果；
4. 修改示例，按 **Ctrl+S** 保存；
5. 按 **Ctrl+Shift+P** 打开命令面板，搜索“主题”切换外观；
6. 按 **Ctrl+Shift+F** 体验全局搜索。

## 验收

- 新用户无需教程即可完成 F5 运行；
- 示例文件可修改并保存；
- 主题切换后界面无不可读文字；
- 全程 ≤5 分钟。

## 说明

- Lite 版默认不收集遥测；
- 市场/评分入口默认隐藏，可在 `QINGCAO_LITE=0` 下恢复。
