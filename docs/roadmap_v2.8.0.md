## v2.8.0 候选功能（按优先级）

### P0 多实例文件变更广播（原已知限制）

**问题**：两个实例同时打开同一文件时，各自保存不会通知对方，
后保存会覆盖先保存。

**方案（QLocalServer/QLocalSocket 广播）**：

1. 每个实例启动时创建 `QLocalServer`，名称
   `qingcao-instance-<username>`；多实例通过广播发现彼此；
2. 任一实例保存文件后广播 `{"type":"file_saved","path":...,
   "mtime":...,"pid":...}`；
3. 收到广播的实例：若该路径已打开且未修改 → 自动重载；
   已修改 → 弹「磁盘文件已变更，是否重载？」；
4. 隔离：广播只发送路径与 mtime，不传内容；非本用户不可见；
5. 无服务端时静默降级（单实例行为不变）。

**验收**：两个实例打开同一文件，A 保存后 B 在 1s 内重载或弹提示；
单实例无额外开销；断线不影响编辑。

### P1 多实例 GUI 自动化冒烟

把本次手工双开验证固化为脚本 `tools/smoke_multi_instance.py`：
启动两个实例 → 断言窗口数/实例目录 → 安全关闭，纳入 CI。

### P2 拼写检查沙箱二阶段

spell_check 迁移回沙箱：宿主提供「忽略词管理」接口（菜单/右键由宿主
代理），插件只保留 `diagnostics(text)`，完成诊断类插件迁移闭环。

### P3 性能门禁

把 `tools/bench_optimization.py --check` 纳入 CI（自托管，无额度成本），
防止输入延迟/主题切换回退。
