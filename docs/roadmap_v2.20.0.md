# v2.20.0 Roadmap（英文正式版 / mmap 默认开启 / 市场评分）

> 基线版本：v2.19.1
> 状态：规划中
> 编写日期：2026-11-04

---

## 一、主题目标

v2.20.0 把 v2.19 的"可用"推进到"正式交付"：

1. **i18n 官方英文版**：可翻译语料 100% 基础上做人工 QA，英文界面正式可用；
2. **mmap 默认开启评估**：用真实保存路径数据决定是否默认启用增量保存；
3. **市场评分体系**：无服务端前提的本地评分/排序 MVP，为未来在线评分预留接口。

## 三、P1（v2.20.0 必做）

### 1. i18n 官方英文版（✅ 术语表+100% 门禁已落地）
- **QA 批次**：对 597 条语料逐条走查（术语统一：Editor/Panel/Palette/Problem/Snapshot 等）；
- 修复机器组合产生的生硬英文（重点：B2 自动补全的 ~120 条）；
- 语言菜单去掉"预览"措辞；README 增加 English 说明；
- 覆盖率门禁：可翻译语料 100% 纳入 CI（`tools/i18n_coverage.py --check`）；
- 验收：英文界面全路径可用；术语表 `docs/i18n_glossary.md` 入库；无中文残留（代码示例/日志例外）。

### 2. mmap 默认开启评估（数据驱动）
- 埋点（本地日志，不上传）：开启后的保存次数、等长命中率、回退次数、journal 恢复次数；
- 灰度策略：默认关闭 → 设置页显著提示"实验" → 满足条件后默认开启（仅 >10MB 等长修改）；
- 决策门槛（建议）：
  - 回退率 <5%；
  - 无 journal 恢复失败；
  - 保存后文件校验（SHA256 抽检）100% 一致；
- 验收：评估报告 `docs/mmap_default_evaluation.md`；默认值决策 + 回滚方案。

### 3. 市场评分体系（无服务端 MVP）（✅ 本地评分已落地）
- 本地评分：插件详情 1~5 星 + 评论（存 `QSettings`/JSON），卡片显示平均分；
- 排序：评分/下载量（下载量来自注册表字段）；
- 防滥用：本地评分仅本机可见（明确标注"本地评分"）；
- 预留：注册表 schema 增加 `rating` 字段，未来服务端可替换；
- 验收：评分写入/持久化/排序测试；UI 截图；文档 `docs/plugin_rating_mvp.md`。

## 四、P2（v2.20.x）

- 英文版长尾：插件市场 HTML/错误长句 QA；

- 评分：导入/导出评分数据；可选远端评分接口草案；
- 终端功能（审计发现缺失，需独立立项）；
- CI 稳定性：继续观察 fallback 频率，必要时固定分片。

## 五、P3（中长期）

- 市场公网化（GitHub Releases 静态托管方案，待确认）；
- i18n 多语言（日/韩/繁中）与 gettext 迁移；
- mmap 撤销/重做集成与 journal 管理 UI。

## 六、验收标准（v2.20.0）

- 分片并行全量测试通过、ruff 0、CI 全绿；
- 可翻译语料 100% 且英文 QA 通过；
- mmap 评估报告完成并给出默认值决策；
- 市场评分功能可用（本地）；
- 无 P0 回归（发布/多实例/主题/沙箱）。

## 七、风险与依赖

| 风险 | 缓解 |
|---|---|
| 英文 QA 工作量大 | 分批 + 术语表 + 自动化残留检查 |

| 无服务端评分可信度低 | 明确标注"本地评分"，预留服务端 schema |
| 版本节奏 | P1 完成后发 v2.20.0；补丁窗口 2 周 |
