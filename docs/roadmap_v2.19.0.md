---

## 一、主题目标

v2.19.0 把三个"预研/脚手架"推进到**可用**：

1. **mmap 增量编辑实现**：等长行替换接入保存路径（含 journal 备份与回退）；

## 三、P1（v2.19.0 必做）

### 1. mmap 增量编辑实现（✅ M1 已落地：等长补丁/journal/恢复/灰度）

- 触发条件：文件 >10MB、保存内容与磁盘差异**仅限等长字节的行替换**；
- 流程：
  1. 保存前对比新文本与磁盘文本（仅比较变更行）；
  2. 等长 → 写 journal（`data/edit_journal/`）→ mmap 原地补丁 → 校验 → 删除 journal；
  3. 非等长/跨行 → 回退全量重写；
- 安全：journal 保留最近 N 次；崩溃恢复时提示"检测到未完成保存"；
- 开关：QSettings `mmap_incremental_save`（默认关闭，灰度）。
- 验收：50MB 文件单行修改保存 <0.5s；等长/非等长/崩溃恢复三路径测试；数据零损坏。

### 2. i18n 翻译落地（第一批）（✅ 语言菜单/菜单 100%/欢迎页/偏好页/状态栏/对话框；词典 371 条；覆盖率报告）

- 以 `locale/zh_CN/strings.json`（5218 条）为模板，按优先级翻译：
  - 菜单/工具栏/设置页/对话框（预计前 800 条覆盖主要 UI）；
  - 插件市场/问题面板/欢迎页；
- 生成 `locale/en_US/strings.json`；
- UI 字符串逐步替换为 `tr()`（先核心窗口，保持回退）；
- 覆盖率 ≥90% 的页面恢复语言选项；未覆盖项自动回退中文并记录。
- 验收：英文界面主要路径可用；`tr()` 覆盖率脚本输出；语言切换持久化。

### 3. 插件市场公网化

- **部署**：注册表服务 + 静态插件包托管（HTTPS，建议 CDN/对象存储）；
- **自动化**：tag 发布流水线自动构建注册表 + 签名 + 上传（私钥仅 CI 安全变量）；
- **安全**：公钥内置到客户端（`QINGCAO_PLUGIN_PUBKEYS` 默认值可配置）、吊销清单、发布日志；
- **运维**：健康检查、备份、版本回滚；`--check` 纳入发布流水线。
- 验收：公网 URL 可拉取；签名发布闭环；篡改/吊销/断网回退测试通过。

## 七、风险与依赖

| 风险 | 缓解 |
|---|---|
| mmap 原地写崩溃导致文件损坏 | journal + 校验 + 默认关闭灰度 |
| 翻译工作量巨大 | 分批 + 覆盖率驱动，不阻塞主线 |
| 公网服务需要域名/证书/托管 | 先用内网/测试域名，证书用 Let's Encrypt |
| 私钥暴露 | 仅 CI secret，禁止入库；轮换手册已有 |
| 版本节奏 | 完成 P1 后再发 v2.19.0，补丁窗口 2 周 |
