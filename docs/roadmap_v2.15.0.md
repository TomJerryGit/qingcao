## 二、v2.15.0 计划（P1）

1. **插件市场在线化 MVP**（✅ 本地目录兜底已实现）
   - 复用已完备的 market 元数据（category/license/homepage/keywords）；
   - 商店面板：列表/筛选/详情（先只读，不自动安装）；
   - 安装源与安全审查预留接口。
2. **沙箱诊断 UI 增强**（✅ 来源过滤+清除已实现）
   - 问题面板按来源过滤（sandbox:<插件> / LSP / 普通插件）；
   - 点击诊断跳转编辑器行列；
   - “清除沙箱诊断”菜单项。
3. **实例上限设置 UI**（✅ 已实现）
   - 设置对话框增加 1~10 滑杆/下拉，写回 QSettings；
   - 与 `QINGCAO_MAX_INSTANCES` 环境变量优先级说明。
4. **高对比度真机回归**
   - 回归清单 + 自动截图脚本（打包版）；
   - 面板 QSS 让位验证结果记录。

## 三、P2（v2.15.x / v2.16）

- 多实例广播**协议版本协商**（ACK 不兼容降级）（✅ 已实现）；
- 性能门禁智能降级 + 分片数自适应（CI 负载感知）（✅ 智能降级已实现）；
- 跨屏 DPI：单机模拟增强（多屏缩放因子脚本）+ 硬件验证清单；
- 插件沙箱迁移扩展（更多只读插件）。

## 四、P3（中长期）

- 沙箱 RPC 方法白名单自动化审计（CI 生成基线）；
- 插件市场在线安装 + 签名校验；
- 调试器表达式求值 RPC 化（进一步隔离）。

## 五、验收标准（v2.15.0）

- 分片并行全量测试通过、ruff 0；
- 沙箱诊断聚合：多文件打开时问题面板出现多个文件分组；
- 安全复核：`_safe_eval` 单测通过，审计文档入库；
- 无 P0 回归（主题/沙箱/多实例/发布流水线）。

## 六、风险与依赖

- 插件市场在线化依赖服务端/安全审查（可先只读前端）；
- 高对比度真机回归依赖单屏模拟（跨屏仍缺硬件）；
- 自托管 Runner 与本机资源竞争时测试可能变慢（CI 已有容差）。
