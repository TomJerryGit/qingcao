## 1. 跨屏 DPI / 多显示器

自动部分：
```powershell
python tools/verify_display_env.py
# 期望：monitor_count >= 2；记录各屏分辨率与主屏 DPI
```

人工步骤：
1. 将窗口拖到第二台显示器（不同缩放，如 100% vs 150%），观察：
   - 菜单/工具栏/状态栏字体是否模糊或错位
   - 停靠面板（问题/大纲/终端）宽度是否被错误放大
2. 在 150% 缩放屏幕上切换主题，确认颜色与边框一致
3. 跨屏拖动窗口往返 3 次，确认无崩溃、无 DPI 缓存错乱
4. 记录结果到下表

| 场景 | 结果 | 备注 |
|---|---|---|
| 100% → 150% 拖动 | ⬜ | |
| 150% → 100% 拖动 | ⬜ | |
| 跨屏切换主题 | ⬜ | |

## 2. 高对比度模式

自动检查：`verify_display_env.py` 输出 `high_contrast`。

人工步骤：
1. 设置 → 辅助功能 → 高对比度 → 开启（如“高对比度黑色”）
2. 启动编辑器，检查：菜单文字/选中行/当前行高亮/括号匹配/滚动条
3. 切换应用内主题，确认不与系统高对比度冲突（必要时应用内主题应让位）
4. 关闭高对比度，确认恢复正常

| 场景 | 结果 | 备注 |
|---|---|---|
| 系统高对比度 + 默认主题 | ⬜ | |
| 系统高对比度 + 深色主题 | ⬜ | |
| 关闭后恢复 | ⬜ | |

## 3. 多实例协作（回归）

```powershell
python main.py --new-window
python main.py --new-window
```
1. 两个实例打开同一文件 → A 保存 → B 应自动重载/询问
2. 实例 A 打开新文件 → 实例 B 状态栏提示“其它实例已打开”
3. 关闭实例 → 另一个实例状态栏提示
4. 退出全部实例 → 检查 `data/instances/` 无陈旧目录残留
