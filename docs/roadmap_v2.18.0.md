# v2.18.0 Roadmap（市场服务化 / 可维护性 / 真机验证）

> 基线版本：v2.17.1
> 状态：规划中
> 编写日期：2026-11-02

---

## 一、主题目标

v2.18.0 从"本地工程化"走向"可分发、可维护、可真机验证"：

1. **插件市场在线服务化 MVP**：本地/内网注册表服务 + 发布脚本 + Ed25519 签名发布；
2. **可维护性重构**：拆分巨型 `main_window.py`，菜单/面板注册化；
3. **真机验证体系**：NVDA、跨屏 DPI、高对比度真机检查清单落地执行；
4. **稳定性**：利用已采集 WER dump 分析 CI 原生崩溃根因。

## 三、P1（v2.18.0 必做）

### 1. 插件市场在线服务化 MVP（✅ 已实现：注册表服务/签名发布/端到端验证）
- 本地/内网**注册表服务**（静态 JSON + HTTP，可选 Flask/FastAPI 或 http.server）；
- 注册表生成工具：扫描本地插件 → 生成 market catalog（含 file_hash/signature/signature_algo）；
- **签名发布脚本**：`sign_plugin.py` 接入发布流程，输出 SHA256 + Ed25519 签名；
- 市场 UI 对接真实 `registry_url`（当前已支持配置），验证在线安装闭环（下载→验签→安装→重载）。
- 验收：本地起服务 → 市场安装 wordcount_sandbox 成功；篡改包被拒绝；离线回退正常。

### 2. 可维护性重构（第一批）（✅ 已实现：main_window -43%）
- 拆分 `ui/main_window.py`（4000+ 行）：
  - 菜单构建 → `ui/menus.py`（注册式）；
  - 面板管理 → `ui/panel_registry.py`；
  - 沙箱 UI 逻辑 → `ui/mixins/sandbox_ui_mixin.py`；
- 保持行为不变，测试全绿为硬约束。
- 验收：main_window 行数下降 ≥40%；无回归；导入时间不劣化。

### 3. 真机验证执行（非代码）
- 按 `docs/manual_validation_v2.17_nvda.md` 执行 NVDA 验证并记录；
- 按 `docs/manual_validation_v2.16_multimonitor.md` 执行跨屏 DPI 检查（需双屏）；
- 高对比度真机回归（开启系统 HC → 启动 → 截图 → 恢复）。
- 验收：结果文档 `docs/manual_validation_results_v2.18.md` 入库。

## 六、验收标准（v2.18.0）

- 分片并行全量测试通过、ruff 0、CI 全绿；
- 市场在线安装闭环可用（含验签失败拒绝路径测试）；
- main_window 重构后行数下降 ≥40% 且无回归；
- 真机验证结果文档入库，遗留问题登记；
- 无 P0 回归（多实例/沙箱/主题/发布流水线）。

## 七、风险与依赖

| 风险 | 缓解 |
|---|---|
| 重构引入回归 | 小步提交 + 每次全量测试 + 行为不变原则 |
| 在线服务依赖网络/端口 | MVP 用本地 http.server，端口可配；离线回退已具备 |
| 真机验证依赖硬件 | NVDA 可安装；跨屏 DPI 需双屏（遗留登记） |
| dump 分析依赖符号 | 先看栈顶模块；必要时用 Qt 公共符号 |

## 八、版本节奏建议

- v2.18.0 主线完成后不再连续发补丁版；
- 补丁窗口：每 2 周一个 patch 窗口，先灰度验证再发布。
