## 四、v2.22 建议顺序

### P1 稳定性（最高优先）
1. **崩溃根因排查**：0x8001010d + 后台线程 DNS/网络调用；检查 requests/urllib3 在 QThread/关闭阶段的调用；
   - 为所有网络调用设超时（已有则审计）；
   - 关闭/退出时取消未完成网络任务，避免线程析构期调用 COM；
   - 网络异常统一捕获（含 RPC/COM 错误），不冒泡到 Qt 线程。
2. **崩溃面包屑**：关键路径记录阶段日志，便于下次定位。
3. **性能回归门禁**：50MB 打开、启动、主题重应用纳入阈值；趋势报告纳入版本说明。

### P2 体验验证（低成本，消除"没试过"）
- 提供 3 条冒烟清单：终端（新标签/执行/关闭）、语言切换（繁中/日文/韩文）、市场在线安装与更新；
- 用「帮助 → 反馈与建议」收集结果，按问题修复。

### P3 功能（依据反馈再启动）
- 终端 PTY/命令历史（仅当终端被使用后）；
- 日韩长尾翻译；
- 评分静态聚合（GitHub Releases 只读）；
- mmap 默认开启（改进埋点 target 字段，继续灰度）。

## 四、验收标准（v2.22.0）
- 无新增崩溃类型；0x8001010d 类问题有结论（修复或明确不复发条件）；
- 性能阈值全绿且趋势无回归；
- 完成一轮体验冒烟并收集至少 3 条真实反馈；
- 日韩试点/终端无 P0 回归。
