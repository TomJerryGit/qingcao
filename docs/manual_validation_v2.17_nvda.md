# NVDA 屏幕阅读器验证清单（v2.17.x）

> NVDA 需在真实桌面运行（本清单由人工执行）；自动化部分由
> `tools/audit_keyboard_a11y.py` 覆盖（可访问名称/焦点控件）。

## 准备

1. 安装 NVDA（中文语音）；
2. 启动青草编辑器，保持主窗口在前台；
3. 开启 NVDA「语音查看器」便于记录。

## 检查项

| # | 操作 | 期望朗读 |
|---|---|---|
| 1 | Tab 到主工具栏 | 「新建/打开/保存」等按钮名称 |
| 2 | Tab 到标签栏 | 当前文件名 |
| 3 | 打开「问题」面板并 Tab | 「问题」面板名 + 树控件名称 |
| 4 | 打开插件市场 | 「插件市场」标题、搜索框、列表项名称 |
| 5 | 打开设置 → 常规 | 各分组标题、界面字体缩放控件名称 |
| 6 | 状态栏 | 行列/编码等状态文本 |
| 7 | 弹窗（如崩溃恢复） | 标题 + 按钮 |
