# v2.17.0 Roadmap（市场体验 / 大文件性能 / 无障碍深化）

> 基线版本：v2.16.1
> 状态：规划中
> 编写日期：2026-10-30

---

## 一、主题目标

v2.17.0 聚焦三条主轴：

1. **插件市场从“能看能装”到“好用可信”**（安全状态、筛选、依赖、失败回滚）；
2. **大文件场景性能与可用性**（打开/搜索/编辑/诊断的 10MB+ 表现）；
3. **无障碍深化**（键盘/焦点/字体缩放/高对比度回归 + 屏幕阅读器基础支持）。

---

## 二、现状基线（v2.16.1）

### 市场 UI

- 已有：插件列表/分类/排序、详情对话框、安装进度、注册表 URL 可配置、
  安全状态展示（未签名/SHA256/HMAC/Ed25519/已吊销）、离线本地目录兜底；
- 缺失：安全状态**筛选/排序**、依赖预检结果、失败回滚、安装后重载提示、
  批量更新、来源标识（官方/本地/第三方）。

### 性能阈值（bench_optimization.py，单位秒）

| 指标 | 阈值 |
|---|---|
| mainwindow | 2.5 |
| theme_reapply | 0.05 |
| typing_2000 | 0.20 |
| open_1mb | 1.2 |
| open_10mb | 1.5 |
| open_py_2mb | 1.5 |
| event_10k | 0.6 |
| session_save | 0.4 |

- 实时沙箱诊断大文件阈值：`MAX_LIVE_DIAGNOSTICS_BYTES = 5MB`；
- 列编辑 10 万行预算 60s（实测远低于）。

### 无障碍

- 已实现：系统高对比度自动适配（含面板 QSS 让位）、窗口/欢迎页调色板同步、
  高对比度模拟工具、主题 E2E 截图基线（4 主题 × 面板/窗口）；
- 缺口：键盘全路径导航与焦点可见性审计、Qt Accessibility 名称/角色、
  字体缩放（UI 整体缩放而非仅编辑器字号）、减少动画/动效开关、
  屏幕阅读器验证（NVDA/讲述人）。

## 三、P1（v2.17.0 必做）

### 1. 插件市场在线安装 UI 完善
- 安全状态**筛选与排序**（仅 Ed25519 / 未签名 / 已吊销）；
- 来源标识徽章：官方 / 本地目录 / 第三方；
- 安装前**依赖预检**（缺失依赖列出并可一键安装）；
- 安装失败**回滚**（解压前校验失败/解压中断恢复）；
- 安装成功提示「重载插件/重启生效」。
- 验收：签名失败/依赖缺失/正常安装三条路径均有单测与 UI 冒烟。

### 2. 大文件性能
- **大文件模式**：>10MB 自动关闭折叠/彩虹缩进/行号动画等重绘项；
- 打开 50MB 文本预算 **< 3s**（当前 10MB 1.5s 基线外推验证）；
- 全局搜索大文件预算（>10MB 提示/后台搜索）；
- 实时沙箱诊断阈值可配置（默认 5MB，用户体验设置项）；
- 性能门禁新增 50MB 打开与折叠关闭回归用例。

### 3. 无障碍深化
- **键盘导航审计**：主菜单/面板/对话框全路径 Tab/快捷键可达；
- **焦点可见性**：统一焦点环样式（含高对比度模式）；
- **Qt Accessibility 基础**：为关键控件设置 accessibleName/Description；
- **字体缩放**：设置项 0.8×~2.0× 全局 UI 缩放（替代仅编辑器字号）；
- **减少动效**开关（遵循系统动画设置）；
- 回归：高对比度 + 字体缩放 + 主题三组合的 E2E 截图基线。

## 六、验收标准（v2.17.0）

- 分片并行全量测试通过、ruff 0；
- 市场：安全筛选/依赖预检/失败回滚路径有测试；
- 性能：50MB 打开 < 3s；性能门禁新增用例通过；
- 无障碍：键盘导航审计清单全绿；高对比度+缩放 E2E 基线通过；
- 无 P0 回归（多实例/沙箱/主题/发布流水线）。

## 七、风险与依赖

- 50MB 性能依赖机器差异，CI 需 `--auto` 容差与独立基准；
- Qt Accessibility 在 Windows 上依赖平台桥接，需真机 NVDA 验证；
- 市场 UI 依赖注册表数据质量（签名/依赖字段完备度）；
- 字体缩放可能暴露硬编码尺寸布局问题，需要分批排查。
