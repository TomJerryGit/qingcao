# 终端 MVP（v2.21 P1-1）

## 功能
- 视图 → 面板 → 终端；底部停靠面板；
- 单命令执行（QProcess 异步）：输入命令 Enter 执行，输出/错误合并回显；
- `cd <dir>` 切换工作目录（默认项目根/当前目录）；
- 清屏、复制输出；
- 关闭面板或退出时 terminate→kill，避免僵尸进程；
- 主题适配（refresh_theme）。

## 明确非目标
- 不做完整 PTY/ANSI 渲染（首版按文本回显）；
- 不自动执行命令、不落盘命令历史。

## 测试
`tests/test_v221_terminal.py`：启动/回显/清屏/cd/关闭清理/接线静态检查。
