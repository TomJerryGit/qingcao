# 青草编辑器 v2.3.0 发布说明

> 发布日期：2026-10-22 · 平台：Windows x64 · 便携版（免安装）
> 版本权威来源：`version.py`（`2.3.0`）

---

## 一句话概括

v2.3.0 是**插件生态 + Notepad++ 对齐**版本：插件可声明式扩展（语言包、
符号大纲、模板脚手架、事件生命周期契约），UI 补齐 NPP 经典交互
（搜索/宏/运行/窗口/编码/语言/设置菜单、状态栏分段、工具栏图标模式、
打印预览），插件商店具备**兼容性徽章 + 门控 + 一键全部更新**。

---

## 插件平台（生态能力）

### 声明式语言包（Notepad++ UDL 等价）
投放 `data/language_packs/*.qingcao-lang.json` 即可新增语言高亮：
关键字/行注释/块注释/字符串/数字/标识符，颜色跟随主题；>1MB 文档自动退化。

### 插件符号提供者 → 大纲
`api.register_symbol_provider()`（等价 NPP `functionList.xml`）：
插件为新语言贡献符号，合并进「大纲」面板；`markdown_preview` 已用其提供
Markdown 标题大纲。

### 插件模板脚手架
`python tools/new_plugin.py --name foo`：一键生成符合规范的插件骨架
（manifest 默认过 conformance；10 个扩展点可选的示例代码）。

### 事件生命周期契约
`docs/event_lifecycle.md`：15 个事件的触发时机、主线程派发、顺序保证；
`tests/test_event_lifecycle.py` 锁定"文档与代码一致"（新增事件漏文档即失败）。

### 能力探测与事件目录
`api.get_api_capabilities()`（11 个扩展点 + 权限 + 事件）与
`api.list_events()`（15 个事件），插件可运行时判断宿主能力。

### 插件商店
- **兼容性门控**：`min_app_version` / `max_app_version` 在安装、更新、
  批量更新、详情页、列表行内全部生效；不兼容直接拒绝并说明原因；
- **兼容性徽章**：列表行 ✅ 兼容 / ⚠️ 不兼容（tooltip 给原因），
  不兼容插件安装/更新按钮置灰；
- **「⬆ 全部更新」按钮**：批量更新并自动跳过不兼容项；
- 详情页新增「更新地址」「更新日志」。

---

## UI（对齐 Notepad++）

- **菜单重组**：新增「搜索 / 宏 / 运行 / 窗口 / 编码 / 语言 / 设置」菜单
  （非破坏式：不新增快捷键，旧入口与命令面板保留）；
- **状态栏**：行/列可点击跳转到行；「长度」段点击弹出统计摘要
  （行/字符/词/字节）；编码、EOL 点击切换菜单；
- **工具栏图标模式**：视图菜单开关，emoji 动态生成 QIcon，
  无需图片资源；
- **欢迎页可关闭**：关闭后启动直达编辑区（偏好持久化）；
- **打印 / 打印预览**：文件菜单，QTextDocument + QPrinter，
  等宽 10pt 渲染。

## 修复的关键缺陷

- 保存 `os.replace` 瞬态占用 → 10 次退避重试（不再静默丢保存）；
- UTF-16/32 被误判二进制、保存丢 BOM、混合行尾被统一改写；
- 草稿恢复永远为空（`list_drafts` 调用名错误）；
- 主题未应用到停靠面板（浅色主题下面板全黑）；
- 状态栏文字白底白字不可见；
- 多屏窗口几何恢复跑丢、200% 缩放编辑器只剩 3 行；
- Actions 发版：artifact v3 停用、缺 `contents: write`、cp1252 编码崩溃。
