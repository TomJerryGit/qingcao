## v2.11.0 候选（按优先级）

### P0 沙箱配置热更新

- 插件配置保存后无需重启即生效（当前仅启动/手动保存下发）；
- 增加「配置变更事件」广播到已打开编辑器；
- 验收：设置保存后诊断/菜单即时反映新配置。

### P1 诊断实时化

- 编辑停止输入 500ms 后自动跑沙箱诊断（可开关，默认关闭防卡顿）；
- 与性能门禁联动（CI 已有 bench 门禁）。

### P2 真机验证补全（需用户配合）

- 双显示器 DPI 拖动清单执行（工具已就绪）；
- 高对比度模式手工验证（清单已就绪）；
- 结果回填 `docs/manual_validation_results_v2.11.md`；
- **待查（v2.10.0 单机验证发现）**：offscreen + 125% 缩放 +
  多测试文件连续创建/销毁 MainWindow 时出现 0xC0000005 崩溃
  （单文件/150% 正常），需定位是否为 PyQt5 off-screen 平台问题或
  应用侧窗口销毁顺序问题。

### P3 工程与发布

- Release 自动附加「相对上一版本体积变化」；
- CI 增加 Python 版本矩阵（3.11/3.12，自托管 Runner）；
- Runner 服务化（需管理员凭据，否则保留 Startup 自启）。
