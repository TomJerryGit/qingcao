# 青草编辑器 v2.19.0 发布说明

> 类型：**Alpha 预览版**（mmap 实验功能 + i18n 收口）
> 版本：2.19.0

## 新增
- **mmap 增量保存（M1，实验，默认关闭）**：大文件等长修改原地补丁 + 区间级 journal + 崩溃恢复；
  50MB 单行保存实测 0.36s；非等长/失败自动回退全量写盘。
- **i18n 收口**：可翻译语料 **597/597=100%**；设置 → 界面语言（简体中文/English，重启生效）；
  菜单 100%、欢迎页/偏好页/状态栏/消息框/对话框/技巧/市场 HTML 全部英文覆盖；
  词典 979 条。
- 主题菜单修复、四项设置 UI（mmap/大文件阈值/诊断阈值/市场 Token）、占位菜单隐藏。

## 验证
- 分片并行全量测试通过；CI（自托管）test/test-py312 全绿。

## 注意
1. Alpha 版本建议备份重要数据；
2. mmap 增量保存默认关闭，需在设置或环境变量开启；
