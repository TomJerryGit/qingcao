# 功能冻结清单（Lite / 免费版）

## 保留并持续维护

| 功能 | 说明 |
|---|---|
| 编辑器核心 | 标签、搜索、替换、编码、主题（保留 2–3 套） |
| Python 运行/调试 | F5 调试、内嵌运行控制台、断点/单步/变量 |
| AI 助手 | 可选；本地 Ollama / 自备 Key；不强依赖 |
| 插件 API | 保留接口，内置少量插件 |
| 安装/便携包 | 安装器 + ZIP |
| 崩溃日志 | 本地导出，不自动上传 |

## 冻结（隐藏入口，不再投入）

| 功能 | 处理 |
|---|---|
| 插件市场/评分/使用统计 | 隐藏入口，停止运营 |
| 主题市场 | 隐藏 |
| Java 调试/测试 | 不承诺；Java 仅保留“实验性单文件运行” |
| 多语言深度支持 | 保留编辑/高亮；LSP 需用户自行安装 |
| 自动更新复杂逻辑 | 改为“检查 GitHub Release” |
| 实验性面板 | 默认隐藏 |

## 删除/归档候选（下一版本评估）

- 使用统计仪表盘；
- 市场评分邀请；
- 主题市场；
- 与核心编辑无关的实验插件。

## 冻结例外

仅以下情况解冻：

1. 安全漏洞；
2. 核心任务阻断；
3. 已有真实用户明确要求且维护成本 < 1 天。

## 验收

- 主界面默认只显示核心面板；
- 冻结功能不出现在新手引导；
- README/发布说明不再宣传冻结功能。
